# Requirements

## Functional Requirements

1. The system shall allow a student to submit a complaint.
2. The system shall generate a unique complaint ID.
3. The system shall store student and room information.
4. The system shall categorize complaints.
5. The system shall assign complaint priority.
6. The system shall display all complaints.
7. The system shall search complaints.
8. The system shall update status and priority.
9. The system shall delete complaints.
10. The system shall display pending and resolved complaints.
11. The system shall display complaint statistics.
12. The system shall save complaint records to a file.
13. The system shall load saved records when restarted.

## Non-Functional Requirements

- Simple console-based interface.
- Easy to understand and maintain.
- Basic input validation.
- Data should persist between program executions.
- The program should handle invalid numeric input without crashing.

## Software Requirements

- Java JDK 17 or later
- VS Code / IntelliJ IDEA / Eclipse
- Git
- GitHub

## Hardware Requirements

- 4 GB RAM or more
- Any modern computer capable of running Java
